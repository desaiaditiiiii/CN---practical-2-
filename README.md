
# Computer Networks – Practical 2

## Overview
This repository contains the implementation and documentation of Computer Networks Practical 2.

The practical demonstrates client-server communication using Python socket programming.

## Objectives
- Understand client-server architecture.
- Establish communication between a client and a server.
- Understand socket-based communication.
- Execute client and server programs.
- Observe communication through terminal outputs.

## Technologies Used
- Python
- Socket Programming
- Visual Studio Code
- Command Prompt (CMD)

## How to Run

### 1. Start the Server

Open the terminal and execute:

```bash
python server.py
```

### 2. Run the Client

Open another terminal and execute:

```bash
python client.py
```

Follow the prompts displayed by the client program to establish communication with the server.

Terminal screenshots demonstrating the execution of the server and client programs are available in the `screenshots/` folder.
